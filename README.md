# inn-gen-extension

## Гайд по установке
1. Скачиваем архив с собранной [утиллитой](https://github.com/StephanYorchenko/inn-gen-extension/blob/master/build.zip)
2. Распаковываем
3. Переходим в список расширений в браузере (ввести в адресную строку chrome://extensions или browser://extensions );
4. Включаем режим разработчика (в правом верхнем углу)
5. Нажимаем "Загрузить распакованное расширение"
6. Выбираем ранее распакованную папку

## Что имеем
1. Контекстное меню с возможностью вставлять инн физлица, юрлица и снилс
2. Небольшой ui с тем же функционалом в меню расширения. Также в процессе разработки подтягивание реальных данных для копирования из открытых источников
